# 字字动画图片 / 视频通用插件

用于处理字字动画内因接口地址、请求格式、模型适配和任务流程不匹配导致的插件提交失败、模型选择及成品获取等问题。

包含图片、视频两套插件，支持填写自己的接口网址和 API Key，适配 New API、Sub2API、其他 OpenAI 兼容接口及画境。

**开源作者微信：wllydydyqr** · MIT 开源

## 安装

1. 退出字字动画。
2. 将本文件夹中的 **`user_resources` 整个合并到字字动画主程序所在目录**。
3. 重新打开字字动画，在模型设置中选择“通用图像插件 · 画境”或“通用视频插件 · 画境”。

图片、视频插件可分别配置服务商，与原画境专用插件可并存。

## 使用

打开对应插件的设置页面，按以下顺序操作：

**选择接口类型 → 填写接口网址和密钥 → 获取模型 / 测试连接 → 选择模型 → 保存设置。**

保存后，回到字字动画分镜中正常生成图片或视频。只填域名会自动补 `/v1`；服务商使用特殊路径时，请按其要求填写完整地址。

## 提交失败先检查

- **连接或密钥报错**：核对接口网址、密钥、账号权限和余额。
- **模型或接口报错**：确认服务商为当前密钥开放了对应的图片或视频接口；模型 ID 也可手动填写。
- **等待超时或下载异常**：先查看服务商后台的原任务，确认任务状态后再决定是否重试，避免重复计费。

详细适配范围和更多排查步骤见[详细说明](参考资料/详细说明.md)。反馈时请提供错误提示、字字动画版本、插件类型和模型 ID。
