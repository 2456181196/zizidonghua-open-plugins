# 字字动画通用插件 · 画境维护

MIT 开源。包含图片与视频两套插件，允许使用自己的服务商地址与 API Key。

**开源作者微信：wllydydyqr**。图片和视频插件的设置页面内也固定显示此联系方式。

## 这个插件解决什么问题

本项目针对字字动画内图片、视频插件接入时，因接口地址、请求格式、模型映射和异步任务处理不匹配而产生的提交失败、模型选择不便、结果获取异常等问题，提供一套可自行配置和修改的通用接入方案。

- 自定义接口网址和 API Key，适配 New API、Sub2API 及其他 OpenAI 兼容接口。
- 从当前密钥查询模型列表，也支持手动填写服务商提供的模型别名。
- 图片支持文字生成、参考图编辑，以及同步或可选异步请求。
- 视频支持提交任务、查询进度和下载成品；画境模式保留专用参考素材能力。
- 图片、视频分为两套独立插件，各自保存设置，继续在字字动画原有分镜内使用。

本项目处理的是已适配接口的接入和任务流程；服务商账号权限、余额、模型开放情况及网络状态仍会影响请求结果。建议先获取模型并测试连接，再提交生成任务。

## 安装与使用

1. 解压安装包，把 `user_resources` 合并到字字动画主程序所在目录。
2. 重启字字动画，在模型设置选择“通用图像插件 · 画境”或“通用视频插件 · 画境”。
3. 选择 New API、Sub2API、其他 OpenAI 兼容接口或画境，填写 API 基础地址和对应密钥。
4. 点击“获取模型 / 测试连接”，从列表选择模型或填写站点给出的模型 ID，再保存设置。
5. 在原有分镜中生成；成品按宿主输出槽位自动保存到作品目录。

只填域名会补 `/v1`；也支持完整的 `/openai/v1` 等前缀。切换站点时重新填写对应密钥。
图片和视频各自保存连接设置，可连接不同站点。插件与原画境专用插件使用不同目录，可并存。

## 兼容范围

| 类型 | 模型列表 | 图片 | 视频 |
| --- | --- | --- | --- |
| New API | `GET /v1/models` | 同步生成、multipart 编辑；URL / Base64 成品 | OpenAI `/v1/videos` 任务协议；可选旧 `/v1/video/generations` |
| Sub2API | `GET /v1/models` | 同步生成、编辑；可选 `/images/generations/async` 和 `/images/edits/async` | `/v1/videos`、任务查询与成品下载，具体由站点分组开放 |
| 其他 OpenAI 兼容 | `GET /v1/models` | 同步生成 / 编辑 | `/v1/videos` 兼容协议 |
| 画境 | 当前密钥实际开放模型 | 专用异步生成 / 多图参考 | 专用视频接口，首尾帧和音视频参考 |

New API / Sub2API 的版本、模型映射、账号分组及管理员开关会影响实际能力；出现在模型列表里不等于所有媒体接口均已开放。插件原样使用返回的模型 ID，不把自定义别名改写成固定模型。

Sub2API 异步图片默认需要站点启用相应的对象存储功能；404 时可手动选择同步模式。图片同步接口可能耗时较长，请把插件等待和服务商代理超时设置为足够的范围。提交连接中断时先检查服务商任务记录，再决定重试。

通用视频协议支持文字或一张参考图。画境接口类型保留该服务专有的首尾帧、视频和音频参考；其他厂商特有参数可按文档填入“额外请求参数 JSON”。每个宿主输出槽位提交一次，使用服务商返回的原成品，不自动重复提交付费请求。

Sub2API 视频采用其 Grok/xAI JSON 格式（`duration`、`aspect_ratio`、`image.url`），本地参考图编码为 data URL；New API / 其他 OpenAI 视频采用 `seconds` 和 `input_reference` multipart 参考图。站点必须为所选分组和模型开放对应能力。

## 提交失败时怎么检查

1. 重新核对接口类型、API 基础地址和这个站点对应的密钥。只填域名会自动补 `/v1`；带前缀的站点请填写完整前缀。
2. 点击“获取模型 / 测试连接”，确认当前密钥能读取模型；选择模型后保存设置。模型别名按服务商实际配置填写。
3. 图片接口遇到 404 时，确认服务商开放了生成或编辑接口；Sub2API 异步模式还需要站点开启相应功能，可在设置中选择同步请求方式。
4. 视频接口遇到 404 时，按服务商协议选择 `/v1/videos` 或 New API 旧版接口；模型列表可见与媒体接口已开放需要分别确认。
5. 等待超时或连接中断时，先查看服务商后台是否已经创建原任务，再决定是否重新提交，避免重复计费。
6. 提交成功但成品获取异常时，核对任务状态、成品链接的可访问性和输出目录权限。反馈问题时请附错误提示、插件类型、服务商类型和模型 ID。

## 动态画境推荐

插件设置页底部显示标有“推广 · 画境推荐”的文字卡片。公开配置来源：

`https://huajingart.cn/api/plugins/promotion`

插件通过公开配置读取推广开关、文字与 HTTPS 跳转链接，联网时定期刷新。此包提供插件客户端的读取及展示代码。

配置服务离线时读取本机最近 24 小时缓存；没有可用缓存时显示源码内的默认画境推荐。生成流程不依赖推荐接口。

## 本地数据和隐私

每套插件在自己的 `user_resources/plugins/{image_plugins|video_plugins}/huajing-open-{image|video}/config.json` 保存设置。`promotion-cache.json` 只保存广告文案缓存。API Key 以配置文件形式保存在本机，请妥善保管。

模型查询、提示词、参考素材与生成请求发送到用户填写的服务商。插件获取推广配置时，使用独立的无模型密钥、无提示词和无素材的请求；只附带插件版本 User-Agent。广告服务器和用户主动打开的网站仍会收到正常网络请求的来源 IP。插件不包含点击统计或安装标识。

## 开发与发布

Python 依赖只有 `requests`。入口遵循字字动画的 `get_info/get_params/load_params/handle_action/generate(context)` 公开插件契约；HTML 使用宿主 PluginSDK。

安装包不包含宿主软件或 PluginSDK；二者由字字动画提供。`huajing_compat.py` 来自画境自己维护的插件 2.0.2，保留专用接口与分镜参考兼容层。

开源范围为图片、视频两套插件的客户端源码。开源使用者可按 MIT 许可证修改、分发插件或移除推广位；保留版权与许可声明。

本目录包含完整插件源码和 MIT 许可证，可上传到自己的开源仓库。发布用的简短介绍见 `开源发布说明.md`，安装入口见根目录的 `先看这里.txt`。公开包未附带个人密钥、运行配置和生成记录；后续发布时也请排除 `config.json`、缓存、账户、数据库、日志及 `.env`。
