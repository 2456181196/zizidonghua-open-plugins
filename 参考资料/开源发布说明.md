# 字字动画图片 / 视频通用插件开源

为了解决字字动画内插件接入时出现的提交失败、模型选择不便、结果获取异常等问题，我把图片和视频两套通用插件整理开源了。

这个项目主要适配接口地址、请求格式、模型映射、异步任务查询和成品下载等接入环节。用户可以填写自己的接口网址和 API Key，获取模型列表后选择模型，继续在字字动画原有分镜中生成。

## 已包含

- 图片、视频两套独立插件，可分别配置服务商。
- New API、Sub2API、其他 OpenAI 兼容接口及画境接入。
- 模型列表查询、自定义模型 ID、图片生成和参考图编辑。
- 视频任务提交、状态查询及成品下载。
- 完整源码、安装与排查说明、两套界面预览及 MIT 许可证。

## 使用方法

将 `user_resources` 合并到字字动画主程序所在目录，重启软件，选择对应插件，填写网址与密钥，获取模型并保存设置。详细步骤见根目录的 `README.md` 或 `先看这里.txt`。
