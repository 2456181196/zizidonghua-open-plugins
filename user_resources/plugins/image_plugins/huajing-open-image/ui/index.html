选择模型

模型列表按服务商返回的 ID 使用。别名没有标明类型时，也可以手动选择。

参考图通过图片编辑接口提交；多张参考图是否开放，以模型和服务商配置为准。

通用视频支持文字或一张参考图。画境模式保留首尾帧、音视频参考。各模型支持的时长、尺寸以服务商为准。

接口细节与等待设置

按服务商文档填写；model、prompt、n、stream 由插件管理。

提交中断时请先检查服务商后台的原任务；当前调用内会继续查询已收到编号的任务。
